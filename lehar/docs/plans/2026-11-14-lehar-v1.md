# Lehar v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a signed Android APK of Lehar: a dark, minimal personal music app with a Mood Pad home, a one-screen player with synced lyrics, search, a library, and reliable background playback, streaming via the YouTube player.

**Architecture:** A thin Java shell (no Gradle, no androidx) hosts a background-safe WebView. The WebView serves a bundled HTML/CSS/JS UI from `https://appassets.androidplatform.net/`. The UI's pure engine modules (`ytm`, `lyrics`, `mood`, `queue`) are plain ES modules unit-tested with `node --test`. Native code does HTTP (so CORS does not apply), the MediaSession, the foreground notification and audio focus. JS drives two hidden YouTube IFrame players.

**Tech Stack:** Java 17 source compiled against android-34, aapt2/d8/apksigner (build-tools 35.0.0), vanilla ES modules, IndexedDB, YouTube IFrame API, YouTube Music internal API (`WEB_REMIX`), LRCLIB, Node 22 (`node --test`), Playwright (pre-installed).

**Spec:** `lehar/docs/specs/2026-11-14-lehar-design.md`

## Global Constraints

- Package `app.lehar.music`, versionName `1.0`, versionCode `1`, minSdk 26, targetSdk 34.
- No Gradle, no androidx, no third-party Java or JS runtime libraries. Framework APIs only.
- UI origin: `https://appassets.androidplatform.net/` (never `file://`).
- Visual tokens: bg `#000`, surface `#111317`, line `#22252c`, text `#ECEDEF`, muted `#8A8F99`, accent `#F2B544`. Fonts Outfit + Inter bundled as woff2.
- Default language mix: Hindi 40, Punjabi 30, English 30.
- Repeat guard: exclude a track played in the last 3 hours OR among the last 50 history entries.
- Queue target size 25. Refill from radio when fewer than 5 remain.
- Chip points (energy, valence): Gym (0.9,0.6), Drive (0.65,0.7), Focus (0.3,0.5), Sleep (0.1,0.4), Party (0.95,0.9), Sad (0.25,0.1).
- Mood-tag radius 0.25. Mood tagging happens at ≥50% played.
- The keystore is never committed (public repo). `lehar/.gitignore` contains `*.jks`, `*.keystore`, `build/`.
- User-facing copy is in Hinglish (Roman script), matching the mockups.

## Review Focus

1. **The Songs filter returns "No results" in some regions** (verified from this server). Search must fall back to the Videos filter and still return tracks. Pinned in Task 2.
2. **The same song appears under different titles** ("Kesariya (From …)", "Kesariya | Official Video", "Kesariya [Slowed + Reverb]"). Dedupe must normalise titles so the queue does not feel repetitive, while keeping intentional variants such as "slowed"/"lofi" distinct. Pinned in Task 5.
3. **Fast dot dragging** fires several queue builds. Only the latest build may replace the queue (stale results dropped). Pinned in Task 5 (`createBuildGate`).
4. **App reopened after Android kills it.** Library, history *and* the current queue/position must restore. Pinned in Task 6 (store `session` key) and Task 10.
5. **LRCLIB returns lyrics for a different-length version.** Reject a `get` match whose duration differs by more than 8s, then fall back to search with the same check. Pinned in Task 3.

```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/.."
SDK=/opt/android-sdk; BT=$SDK/build-tools/35.0.0; JAR=$SDK/platforms/android-34/android.jar
OUT=build; rm -rf $OUT && mkdir -p $OUT/{res,gen,classes,dex,apk/assets}
$BT/aapt2 compile --dir android/res -o $OUT/res.zip
$BT/aapt2 link -I $JAR --manifest android/AndroidManifest.xml -o $OUT/base.apk \
  --java $OUT/gen --min-sdk-version 26 --target-sdk-version 34 \
  --version-code 1 --version-name 1.0 $OUT/res.zip
javac -source 17 -target 17 -nowarn -classpath $JAR -d $OUT/classes $(find android/src $OUT/gen -name '*.java')
$BT/d8 --min-api 26 --lib $JAR --output $OUT/dex $(find $OUT/classes -name '*.class')
cp -r www $OUT/apk/assets/www
cp $OUT/base.apk $OUT/unsigned.apk
(cd $OUT/dex && zip -qj ../unsigned.apk classes.dex)
(cd $OUT/apk && zip -qr ../unsigned.apk assets)
$BT/zipalign -f -p 4 $OUT/unsigned.apk $OUT/aligned.apk
KS=$HOME/.lehar/lehar.jks
if [ ! -f "$KS" ]; then mkdir -p ~/.lehar; head -c 18 /dev/urandom | base64 | tr -d '/+=' > ~/.lehar/pass
  keytool -genkeypair -keystore "$KS" -alias lehar -keyalg RSA -keysize 2048 -validity 10000 \
    -storepass "$(cat ~/.lehar/pass)" -keypass "$(cat ~/.lehar/pass)" -dname "CN=Lehar" >/dev/null 2>&1; fi
$BT/apksigner sign --ks "$KS" --ks-pass file:$HOME/.lehar/pass --out $OUT/lehar-1.0.apk $OUT/aligned.apk
$BT/apksigner verify $OUT/lehar-1.0.apk && echo "BUILT $OUT/lehar-1.0.apk"
```

### Task 5: `engine/queue.js`: repeat guard, dedupe, interleave, build gate

**Files:** Create `lehar/www/js/engine/queue.js`, `lehar/test/queue.test.js`

**Interfaces:**
- Consumes: `Track` (Task 2), `distance` (Task 4)
- Produces:
  - `normTitle(title) → string` (lowercases; strips bracketed/piped suffixes and words such as official, video, audio, lyrical, lyrics, full song, 4k, hd, from "…"; keeps variant markers such as slowed, reverb, lofi, remix, unplugged, acoustic, and appends them sorted)
  - `repeatGuard(tracks, history, now, {hours=3, lastN=50}) → Track[]` (history items are `{videoId, at}`, newest last). If the result is empty while the input is not, relax by halving `lastN` and `hours` until something passes, or return the input minus the most recent 5.
  - `dedupe(tracks) → Track[]` (by videoId, then by `normTitle`)
  - `interleave(groups: {[language]: Track[]}, mix) → Track[]` (weighted round-robin following the mix)
  - `nearbyTagged(moodTags, tracksById, point, radius=0.25) → Track[]`
  - `buildQueue({groups, personal, history, now, mix, size=25}) → Track[]`, i.e. interleave → prepend up to 30% personal (interleaved every 3rd slot) → dedupe → repeatGuard → slice(size)
  - `createBuildGate() → { start(): token, isCurrent(token): boolean }` (Review Focus 3)
